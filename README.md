# IOT
Smart Warehouse System
Весовой мониторинг и автоматизация остатков.

Бэкенд-сервис на Go для автоматизации складского учета на основе данных от умных полок с датчиками веса. Система принимает данные о весе в реальном времени, автоматически рассчитывает остаток товаров в штуках и сигнализирует о необходимости пополнения.

Функционал
Мониторинг веса: Прием данных от IoT-датчиков веса через REST API.

Расчет остатков: Автоматическое вычисление количества товара на основе текущего веса нетто и веса единицы продукции.

Оповещение о дефиците: Отслеживание минимально допустимого порога веса (MinWeight) и выставление статуса REFILL при его достижении.

Потокобезопасность: Работа с In-Memory хранилищем защищена с помощью sync.RWMutex для корректной обработки параллельных запросов.

Стек
Язык: Go

Роутер: github.com/gorilla/mux

Архитектура: Многослойная (Handlers -> Service -> Storage) с использованием интерфейсов.

Эндпоинты
Полки
GET /shelves — получить статус и остатки по всем полкам.

POST /shelves — добавить новую полку.

DELETE /shelves/{id} — удалить полку.

PATCH /shelves/weight — обновить текущий вес на полке (запрос от датчика).

Товары
POST /shelves/product — привязать товар к полке (задать параметры веса).

GET /shelves/{id}/product — получить информацию о товаре на полке.

DELETE /shelves/{id}/product — удалить товар с полки.
